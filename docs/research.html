Sanrio Timenet: Kako Hen

Text extraction notes

Current findings for the Japanese Rev 1 ROM. The project does not have a playable English patch yet.

Confirmed findings

  • The supported image is the 1 MiB Japanese Rev 1 ROM documented on the project home page.
  • GCCODE2's relative search for ﾀｽｹﾃｰﾎｼｲﾉ returned two candidates. The saved conversion dump shows たすけてーほしいの at 0x8F665. The surrounding marker bytes still need decoding.
  • The region near 0x89640 contains the opening story recap. The bytes at 0x8964F decode as たすけをもとめる (“asking for help”) with the character mapping used in this region.
  • The public Data Crystal table is explicitly marked as an incomplete draft for an earlier ROM revision. Its known kana mapping helps interpret some bytes, but its full mapping and control codes have not been confirmed for Rev 1.

Provisional translation

The opening recap is only partly decoded near 0x89640. The confirmed fragment たすけをもとめる means “asking for help.” Read alongside the community story-recap reference, the provisional sentence is: “I received a message asking for help from an old man inside the computer.”

The opening phrase includes codes that are not yet identified, so the full sentence is not confirmed. The draft translation ledger separates the provisional line from the confirmed fragment.

Remaining work before a patch

  1. Identify each text encoding and separate dialogue from names, variables, graphics, and other binary data.
  2. Decode the message-control markers and locate the text pointers.
  3. Map the target game's font. Community analysis of the related Future Edition reports that its font lacks the full A–Z alphabet; check the Past Edition ROM and add missing glyphs if needed.
  4. Translate and reinsert the text, then check it in an emulator before building and releasing an IPS patch.
