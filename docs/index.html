Required source ROM

This page distributes patches only. Supply your own legally obtained game file.

Translation progress

GCCODE2 has confirmed dialogue candidates and a passage from the opening story recap. Special markers and multiple text encodings still need to be identified before the full script can be translated and reinserted.

The existing character table is an incomplete draft for an earlier ROM revision. Community research on the related Future Edition reports that its font lacks a complete A–Z alphabet; this still needs to be checked against the Past Edition. Read the extraction notes and draft translation ledger for confirmed offsets and remaining questions.

How to use the patch

  • Obtain the supported Japanese ROM from your own cartridge.
  • Download the English IPS patch when it is released.
  • Apply the patch here or with a standard IPS patcher.
  • Open the new ROM in a Game Boy Color emulator or compatible flash cartridge.
